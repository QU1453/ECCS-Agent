# 计划：安装所有依赖

## 摘要

为 ECCS-Agent 项目安装全部 Python 依赖（`requirements.txt`），并验证可导入、服务可启动。安装本身是幂等操作，已装的会跳过/升级。

## 现状分析（已探查）

- 依赖清单：`requirements.txt`（fastapi / uvicorn / langgraph / langchain-openai / python-dotenv）
- 环境当前状态（python 3.14.7，本会话早前已装过一次）：
  - fastapi 0.141.1 ✅、uvicorn 0.52.4 ✅、langgraph 1.2.11 ✅、langchain-openai 1.6.0 ✅、python-dotenv 1.2.3 ✅（连带 openai 3.7.0、pydantic 2.13.5、langchain-core 1.6.1 等）
  - `pywebview` 在 requirements.txt 中为注释掉的可选项（桌面版 main.py 尚未创建），**不安装**
- 代码侧引用（server.py / agents / tools / memory / config）只用到上述已装包，无隐藏第三方依赖（其余均为标准库）

## 执行步骤

1. **安装**：`python3 -m pip install -r requirements.txt`（在 /workspace 下执行；幂等，已满足版本要求的包自动跳过）
2. **一致性检查**：`python3 -m pip check`（确认无依赖冲突）
3. **导入验证**：`python3 -c "import fastapi, uvicorn, langgraph, langchain_openai, dotenv; print('ok')"`
4. **全量编译验证**：`python3 -m compileall -q server.py config.py agents tools memory`
5. **服务冒烟**：启动 `python3 server.py`，curl `/api/status` 确认 200（装完后停止进程）

## 决策与假设

- 不安装 `pywebview`：requirements.txt 中明确标注"可选，运行 main.py 时再装"，且 main.py 尚不存在
- 不安装 `langgraph-checkpoint-sqlite`：持久化记忆仅为 README 中的规划项，当前用 MemorySaver（内置于 langgraph）即可
- 不改动 requirements.txt（无版本钉扎需求，任务未要求）
- 不涉及 Docker 镜像构建（沙箱无 docker；容器内依赖由 Dockerfile 的 `pip install` 层负责）

## 验证标准

- pip 安装无报错、`pip check` 无冲突
- 核心包全部可导入
- `compileall` 通过；`/api/status` 返回 `{"ok": true, ...}`（当前无 Key，应显示 local-fallback 模式）
